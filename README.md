# ReviewAndroidStudioTemplate
> Android Studio バージョンごとにプロジェクト作成し、その変化をメモするためのリポジトリ

## 方針
* Draft Pull Request で作成したプロジェクトを管理する
    * コメント機能でメモを残しやすいため
* minSdk はAndroid 4.4 にする
* アプリ名は `MyApplication` を設定する
* パッケージ名は `tshion.github.io` を設定する

## 各種リンク
* 入手先: https://developer.android.com/studio/archive
* リリースノート: https://developer.android.com/studio/releases/past-releases/
